# Public AX6600 Field Notes

This is the sanitized GitHub edition of the AX6600 Field Notes site. It preserves the hardware, datapath, recovery, image-lineage and topology topics, with summaries, conclusions and aggregate results only.

Run `python3 website/build.py` from the repository root to regenerate `docs/`, then `python3 website/check.py`. The builder uses only the Python standard library. GitHub Pages serves `docs/` from `main`; all local asset links work under the repository URL prefix.

Do not copy original evidence directories, per-case datasets, detailed reports, packet captures, private configuration, firmware images, keys or raw logs into this tree. Keep sensitive host/network identifiers out of prose, diagrams, JSON, HTML comments and script-embedded data. Node labels are anonymized and are not usable deployment addresses. Preserve qualification limits with every result.

The build is a GitHub Pages export. It contains no Sites hosting identity, credentials, analytics or backend service.
