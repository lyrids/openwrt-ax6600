# Two-router mesh campaign

**16 November 2026, Singapore — preparation complete; testing starting.** Both router preparation chats have completed and are idle. Router A runs installed Image 17 with NSS 11.4 release 6; router B runs installed Image 23. Both use Linux 6.18.60. These observations are campaign-start status, not a stability qualification.

The first planned test is an isolated integrated 5 GHz SAE 802.11s peer link on channel 149, HE80. A wireless-only negative control, bidirectional endpoint traffic, MTU checks, lifecycle tests and a soak are planned as feasible. Independent management access is available for all hosts. Router A's upstream QCN station and selected routing policy are to be preserved. No eMMC kernel updates are authorized for this campaign.

No mesh results are available yet. Earlier NSS 11.4 local mesh startup allocated nodes without a peer; that observation does not establish peer forwarding or acceleration. Results, failures, blockers and crashes will be added as evidence becomes available, with sensitive identifiers and raw evidence excluded.
